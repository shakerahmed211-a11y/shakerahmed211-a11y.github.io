# Spinner Dominoes — الدوّار

لعبة دومينو عربية بواجهة RTL، تدعم التدريب ضد الكمبيوتر وغرفًا خاصة عبر WebSocket. الطقم المستخدم هو **Double‑6 العادي**: القيم من الأبيض (٠) إلى الدُّش (٦)، بإجمالي **٢٨ قطعة**. كل قيمة موجودة على سبع قطع، والدبل محسوب كقطعة واحدة ضمن السبع. لا توجد قيمة ٧ أو جوكر أو قطع إضافية.

## قواعد هذه النسخة

- تُوزّع ٧ قطع لكل لاعب. في مباراة الأربعة لاعبين تُوزع المجموعة كلها؛ وفي المباريات الأقل تبقى القطع غير الموزعة في المخزون.
- تبدأ اليد الأولى بالدُّش (٦–٦)، ثم يتناقص الدبل الافتتاحي كل يد: ٥–٥، ٤–٤، وهكذا حتى الأبيض. تسحب اليد الأولى حتى العثور على الدبل إذا لم يكن في يد أي لاعب.
- تطابق القطعة الرقم المفتوح. ووفق قاعدة الدوّار المنزلية في هذه اللعبة، يفتح الدبل ثلاثة أذرع؛ تُلعب الحركات الثلاث التالية عليها قبل بقية الأطراف.
- إذا لم توجد حركة، اسحب حتى تعثر على قطعة مناسبة أو ينفد المخزون، ثم مرّر. تنتهي اليد عند فراغ يد لاعب أو انسداد اللعب. تحسب نقاط القطع المتبقية، والأقل مجموعًا يفوز بالمباراة.
- قاعدة الأذرع مستوحاة من Spinner، لكن **المجموعة Double‑6 وليست طقم Spinner التجاري**. تفاصيلها موضحة داخل اللعبة وقابلة للتطوير في `src/game.js`.

## التشغيل محليًا

المطلوب Node.js 20 أو أحدث.

```bash
npm start
```

افتح `http://localhost:3000`. يعمل التدريب واللعب الجماعي المحلي على الخادم نفسه. افحص الخدمة من `http://localhost:3000/health`.

```bash
npm test
```

تشمل الاختبارات عدد القطع وتكرار القيم والتوزيع، والحركات القانونية، والسحب والتمرير، واحتساب النقاط ونهاية اليد.

## النشر على GitHub Pages وRender

GitHub Pages يستضيف الملفات الثابتة فقط؛ لا يشغّل WebSocket. لذلك تعمل مباراة الكمبيوتر على Pages، أما الغرف فتحتاج خادم Node.js. ملف `render.yaml` في جذر المستودع يهيئ خدمة مجانية على Render باستخدام هذا المجلد.

1. في Render اختر **New → Blueprint**، واربط المستودع `shakerahmed211-a11y/shakerahmed211-a11y.github.io`.
2. أنشئ الخدمة بالإعدادات الموجودة في `render.yaml` وانتظر نجاح البناء.
3. رابط Render يفتح اللعبة وخادم الغرف معًا. لا يلزم إعداد عنوان WebSocket عند اللعب من رابط Render.
4. لربط نسخة GitHub Pages بالخادم، ضع `wss://<عنوان-الخدمة>/ws` في `public/config.js` ثم ارفع التعديل إلى GitHub.

**حدود الخطة المجانية:** قد توقف Render الخدمة بعد ١٥ دقيقة دون حركة وتحتاج قرابة دقيقة للاستيقاظ. حالة الغرف في هذا الإصدار محفوظة في ذاكرة الخادم؛ إعادة تشغيل الخدمة أو إيقافها تُنهي الغرف. الاتصال الدوري وإعادة الاتصال يعالجان انقطاع الشبكة القصير ما دامت الخدمة وذاكرة الغرفة موجودتين. للاستعمال المستمر يلزم خادم دائم وتخزين مشترك.

## ما يتضمنه المشروع

- `src/game.js`: مجموعة Double‑6، التوزيع، الأذرع، القواعد، النقاط، والخصم الآلي.
- `server.mjs`: HTTP وWebSocket؛ يتحقق الخادم من النقلات ويُرسل يد كل لاعب إليه وحده.
- `public/`: واجهة عربية؛ طاولة SVG متصلة ونقاط دومينو واضحة، مع تخطيط المباراة لملء الشاشة دون تمرير الصفحة رأسيًا.
- `tests/`: اختبارات محرك اللعبة.

إعدادات الغرفة: لاعبان إلى أربعة، فردي أو فرق من أربعة، ٣ أو ٥ أو ١٠ أيادٍ، وسرعة عادية أو سريعة. يتضمن المشروع إعادة اتصال، حالة اتصال اللاعبين، دردشة وكتمها، وردودًا سريعة.
