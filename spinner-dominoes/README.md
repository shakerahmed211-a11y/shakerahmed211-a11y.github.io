# Spinner Dominoes — الدوّار

لعبة متصفح عربية متجاوبة، مبنية بـ Node.js من دون حزم خارجية. تتضمن تدريبًا ضد خصم آلي وغرفًا خاصة متزامنة لحظيًا عبر WebSocket.

## القواعد المعتمدة

اللعبة تستخدم مجموعة دومينو Double‑7 مبسطة: ٣٦ قطعة عادية (من ٠–٠ حتى ٧–٧) و٩ قطع دوّار (واحدة برية لكل قيمة من ٠ إلى ٧، وقطعة دوّار مزدوجة)، بإجمالي ٤٥ قطعة. يبدأ اللعب من ٧–٧، ثم يبدأ كل دور جديد من الرقم التالي نزولًا حتى ٠–٠. يوزّع ١٠ قطع لكل لاعب في مباراة لاعبين، و٧ قطع لكل لاعب عند ٣ أو ٤ لاعبين. إذا لم تكن قطعة البداية في الأيدي، يسحب اللاعب الأول حتى يجدها. بعد الدبل الافتتاحي تُستكمل ثلاثة أذرع، وبعد أي دبل تُلعب الحركات الثلاث التالية على أذرعه قبل فتح بقية الأطراف. قطعة الدوّار البرية تصلح بدل أي رقم، وتُحسب بقيمة ١٠ نقاط. تُضاف قيم القطع المتبقية لكل لاعب عند نهاية اليد؛ الفائز بعد عشر أيادٍ هو صاحب أقل مجموع. تنتهي اليد أيضًا عند انسداد اللعب. هذه قواعد بيتية مستوحاة من Spinner، لأن مجموعة Spinner الأصلية Double‑9 وليست Double‑7.

المصدر الأساسي: [كتيّب القواعد الرسمي (PDF)](https://www.universitygames.com/_files/ugd/05f72c_d7673d78f80443be9c8be357ff9aa083.pdf). نظرة الشركة على المنتج: [University Games — Spinner](https://www.universitygames.com/spinner).

**توضيح تنفيذي:** غرف الأونلاين تدعم 2–4 لاعبين، والتدريب لاعب ضد لاعب آلي. نمط الفرق اختياري لأربعة لاعبين (المقعدان 1 و3 ضد 2 و4) ويجمع مجموع نقاط شريكي الفريق. الطاولة تُرسم كمساحة SVG متصلة: الدبلات بالعرض، والأذرع مفتوحة عند مواضعها، مع تحريك وتكبير مناسبين للموبايل. ترتيب الأذرع مبني على الرسم الثلاثي الفروع في الكتيّب؛ مجموعة Double‑7 هنا تعديل بيتي وليست مجموعة Spinner التجارية الأصلية.

## التشغيل محليًا

المطلوب Node.js 20 أو أحدث.

```bash
npm start
```

افتح [http://localhost:3000](http://localhost:3000). للتحقق من الخدمة افتح `/health`. لا توجد مفاتيح أو قاعدة بيانات مطلوبة. الغرف وحالة الجولات تحفظ في ذاكرة الخادم أثناء تشغيله؛ الغرف الفارغة تُنظف بعد ست ساعات. الرجوع بعد انقطاع الاتصال يعمل إذا بقي الخادم شغالًا وظل مقعد اللاعب محفوظًا.

## الاختبارات

```bash
npm test
```

تغطي الاختبارات عدد القطع والتوزيع والافتتاحية والحركة القانونية والسحب/التمرير واحتساب النقاط وتقدم الأيدي.

## النشر

انشر هذا المجلد كخدمة Node.js طويلة التشغيل على منصة تدعم WebSocket، مثل Render أو Railway أو Fly.io. اضبط أمر البناء على `npm install` (لا توجد تبعيات حاليًا، ويمكن تركه دون بناء) وأمر البدء `npm start`. مرر قيمة المنصة في `PORT`؛ الخادم يقرأها تلقائيًا. لا ترفع اللعبة كملفات GitHub Pages ثابتة فقط، لأن الغرف تحتاج خادم WebSocket دائمًا. تحقّق من سياسة التسعير والنوم/الإيقاف لدى المنصة وقت النشر؛ الخطط المجانية وشروطها تتغير.

### GitHub Pages

بعد نشر المجلد في المستودع، يمكن فتح الواجهة الثابتة على `https://shakerahmed211-a11y.github.io/spinner-dominoes/public/`. مباراة الكمبيوتر تعمل هناك. غرف الأونلاين تحتاج خادم Node/WebSocket منفصلًا؛ بعد نشره، ضع عنوانه الكامل مثل `wss://your-host.example/ws` في `public/config.js` داخل `window.SPINNER_WS_URL`. لا تحوّل عنوان Pages نفسه إلى WebSocket؛ Pages لا يشغّل `server.mjs`.

## البنية

- `src/game.js`: مجموعة القطع، التوزيع، الأذرع، فحص الحركات، التسجيل والخصم الآلي.
- `server.mjs`: خادم HTTP وWebSocket صغير بلا حزم خارجية؛ كل حركة أونلاين تمر عبر التحقق الخادمي، ولا يُرسل للعميل سوى يده الخاصة.
- `public/`: الواجهة العربية، أسلوبها، وتدفق اللعب/الغرف.
- `tests/`: اختبارات محرك القواعد باستخدام `node:test`.

## ما يعمل الآن وما يتطلب تطويرًا إضافيًا

- يعمل: تدريب محلي ضد الذكاء الاصطناعي بثلاث درجات، غرف خاصة برمز دعوة، لعب 2–4 أشخاص، لعب فردي أو فرق من أربعة، اختيار قواعد البداية وسرعة الانتقال وعدد الأيادي (3 أو 5 أو 10)، مزامنة لحظية، تحقق خادمي للحركات، احتفاظ بمقاعد اللاعبين عند انقطاع مؤقت، دردشة وردود سريعة مع كتم، دليل قواعد، تلميحات، صوت اختياري، ومقاسات هاتف/كمبيوتر.
- يحتاج خدمة خارجية فقط للنشر على الإنترنت. لا تتضمن النسخة حسابات مستخدمين أو قاعدة بيانات؛ لذا تنتهي الغرف عند إعادة تشغيل الخادم. لا يوجد مؤقت أدوار أو مراقب.
