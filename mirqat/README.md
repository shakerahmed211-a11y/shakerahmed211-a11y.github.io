# مِرْقَاة — تعلّم النحو العربي بإتقان

**تصميم أحمد شاكر**

منصة عربية عامة للتدريب على النحو، بواجهة متجاوبة مع الهاتف والكمبيوتر.

- ٢٨ درسًا في ٧ وحدات، و٨٤ تمرينًا.
- تشخيص أولي واختبار قصير بعد كل درس.
- فتح الدرس التالي بعد اجتياز السابق بالكامل دون تلميحات.
- تصحيح فوري وأمثلة مشكولة وتدريب على الإعراب.
- مراجعات متباعدة وسجل للأخطاء والنقاط والإتقان.
- استئناف آخر درس وثلاث درجات للصعوبة.
- حفظ محلي مستقل لكل متصفح، مع تصدير التقدم واستعادته.

## التشغيل والنشر

الملف `index.html` ومجلد `assets` هما النسخة الجاهزة للاستضافة. جميع المسارات نسبية، لذلك يعمل الموقع داخل مجلد `mirqat` في GitHub Pages دون خادم خلفي أو مفتاح API.

لتعديل المصدر وإعادة البناء، داخل هذا المجلد:

```sh
npm install
npm run build
```

ثم ارفع ملفات المصدر والنسخة المبنية إلى المستودع. يعيد GitHub Pages نشرها تلقائيًا.

## الخصوصية ونقل التقدم

لا يرسل الموقع إجابات المتعلم أو نقاطه إلى أي خادم؛ تُحفظ في localStorage داخل المتصفح. الخطوط تُحمّل من Google Fonts، مع خطوط بديلة عند تعذر الاتصال. إذا انتقلت من نسخة الموقع القديمة إلى هذا النطاق، صدّر تقدمك من إعدادات النسخة القديمة ثم استعد الملف من إعدادات هذه النسخة. لا تنتقل بيانات المتصفح تلقائيًا بين النطاقات.

المستوى المتقدم يقارن الإجابات الكتابية بالنموذج، متجاهلًا التشكيل والترقيم، وقد لا يقبل جميع الصياغات المكافئة. المسار تدريب متدرج إلى التحليل المتقدم، ولا يمثل شهادة تخصص.
